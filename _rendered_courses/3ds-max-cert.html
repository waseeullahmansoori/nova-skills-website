Detailed Curriculum & Labs

Module 01 UI, Primitives & Spline Modeling 3 Lessons ⌄
Module Focus: Understand the interface and base geometry generation.
  • Viewport Navigation
  • Standard Primitives
  • Spline Creation
Key Concepts: Command PanelSplines
1.1 Interface & Viewports
Taught: Command panel, viewports, object creation.
Learner Lab: Sets up custom UI.
Why It Matters: Navigation is key to speed.
Expected Deliverable: Familiarity with layout.
1.2 Primitives & Transforms
Taught: Move, Rotate, Scale and basic shapes.
Learner Lab: Blocks out a simple furniture piece.
Why It Matters: Foundation of scene building.
Expected Deliverable: Primitive blockout.
1.3 Spline Modeling Basics
Taught: Line tool, vertex types, extrude/lathe.
Learner Lab: Models a classic vase and table profile.
Why It Matters: Essential for architectural details.
Expected Deliverable: Spline-based objects.
🛠️ Hands-on Lab: Model basic room furniture using primitives and splines.
📝 Practical Assignment: Submit 3ds Max file.
💼 Commercial Application: Rapid prototyping.
🎯 Expected Outcome: Basic 3D objects.
Module 02 Poly Modeling & Modifiers 3 Lessons ⌄
Module Focus: Advanced shape creation and manipulation.
  • Editable Poly
  • Sub-object modeling
  • Modifier stack logic
Key Concepts: Editable PolyTurbosmooth
2.1 Editable Poly Tools
Taught: Extrude, Bevel, Connect, Target Weld.
Learner Lab: Models a detailed armchair.
Why It Matters: The core of 3D modeling.
Expected Deliverable: Complex poly model.
2.2 Working with Modifiers
Taught: Bend, Twist, Symmetry, Turbosmooth.
Learner Lab: Applies modifiers to create organic shapes.
Why It Matters: Non-destructive workflow.
Expected Deliverable: Smooth, modified geometry.
2.3 Topology & Edge Flow
Taught: Maintaining quads and clean geometry.
Learner Lab: Optimizes the armchair model.
Why It Matters: Prevents rendering artifacts.
Expected Deliverable: Clean mesh topology.
🛠️ Hands-on Lab: Complete detailed modeling of the armchair.
📝 Practical Assignment: Submit the finalized model.
💼 Commercial Application: Product modeling.
🎯 Expected Outcome: Professional 3D model.
Module 03 Scene Assembly & Lighting 3 Lessons ⌄
Module Focus: Organize assets and prepare for rendering.
  • Layer Management
  • Importing/Merging
  • Basic Lighting
Key Concepts: XRefsScene Explorer
3.1 Scene Organization
Taught: Layer explorer and grouping.
Learner Lab: Organizes a complex room scene.
Why It Matters: Crucial for large projects.
Expected Deliverable: Structured scene file.
3.2 Asset Assembly
Taught: Merging files and XRefs.
Learner Lab: Assembles props into the main room.
Why It Matters: Collaborative workflow.
Expected Deliverable: Complete environment layout.
3.3 Standard Lighting & Cameras
Taught: Placing standard lights and cameras.
Learner Lab: Sets up a basic light rig.
Why It Matters: Prepares scene for rendering.
Expected Deliverable: Lit scene ready for render engines.
🛠️ Hands-on Lab: Assemble and light a full interior room.
📝 Practical Assignment: Submit final scene file.
💼 Commercial Application: ArchViz scene prep.
🎯 Expected Outcome: Organized 3D environment.
