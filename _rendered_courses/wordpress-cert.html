5.1 WordPress SEO Fundamentals
Taught: Search intent, unique page titles and meta descriptions, strict heading hierarchy (one H1 per page, sequential H2/H3), clean URL slugs, internal linking, and descriptive image alt text.
  • Search intent
  • Page titles and meta descriptions
  • Heading hierarchy
  • Clean URLs
  • Internal linking
  • Image alt text
Learner Lab: Optimizes meta tags, headings, and image alt attributes across all 5 business pages.
Why It Matters: Solid on-page SEO ensures the website can be properly understood and indexed by search engines.

5.2 Search Indexing Basics
Taught: XML sitemap generation, search engine indexability checks (disallowing 'discourage search engines' setting), robots.txt overview, and Google Search Console submission basics.
  • XML sitemaps
  • Indexability settings
  • Google Search Console introduction
  • Basic indexing checks
Learner Lab: Verifies the XML sitemap URL and runs pre-launch search indexing readiness checks.
Why It Matters: Accidental noindex settings or missing sitemaps prevent websites from ever ranking on Google.
Expected Deliverable: Verified XML sitemap ready for search engine submission.
5.3 Website Performance
Taught: Image optimization (WebP format, compression, correct dimensions), caching fundamentals, eliminating unnecessary plugins, and auditing with Google PageSpeed Insights and Lighthouse.
  • Image optimization
  • Suitable image formats
  • Caching fundamentals
  • Avoiding unnecessary plugins
  • PageSpeed Insights
  • Lighthouse basics
Learner Lab: Compresses all media assets, activates page caching, and conducts before/after PageSpeed tests.
Why It Matters: Fast-loading websites deliver superior user experiences and rank higher in search results.

5.4 Website Security
Taught: Enforcing strong administrative passwords, principle of least privilege for user accounts, plugin and theme update hygiene, basic login hardening, and automated backup scheduling.
  • Strong authentication

  • Basic website hardening
  • Backup planning
  • Restore awareness
Learner Lab: Hardens admin login credentials, removes dormant themes/plugins, and sets up an automated backup schedule.
Why It Matters: WordPress sites are frequent targets of brute-force attacks; basic hardening prevents compromise.
Expected Deliverable: Security-hardened WordPress setup with active remote backups.

Taught: Verifying backup archives, creating a pre-update testing checklist, running functional link and form checks, responsive viewport testing, and basic accessibility auditing.
  • Backup verification
