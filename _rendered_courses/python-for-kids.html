STEP-BY-STEP MODULES

Detailed Curriculum & Labs

1 Hello, Python! 3 Lessons ⌄
Module Focus: Get comfortable writing basic text-based code and understanding data types.
  • Using the print() statement
  • Variables (strings and integers)
  • Getting user input
  • Basic arithmetic
Key Concepts: StringsVariablesInput/Output
1 First Words in Code
Taught: The print() function and strings.
Learner Lab: Prints messages and creates ASCII art using text.
Why It Matters: The fundamental way programs communicate with users.
Expected Deliverable: A script that outputs formatted text.
2 Boxes of Data: Variables
Taught: Assigning values to variables.
Learner Lab: Creates variables for a character profile (name, age, hobby).
Why It Matters: How computers remember information.
Expected Deliverable: A script that prints variable data.
3 Talking to the Computer
Taught: The input() function.
Learner Lab: Builds a Mad Libs word game.
Why It Matters: Makes programs interactive.
Expected Deliverable: An interactive text script.
🛠️ Hands-on Lab: Write an interactive script that calculates the user's age in days.
📝 Practical Assignment: Submit the Mad Libs project.
💼 Commercial Application: Basic data processing.
🎯 Expected Outcome: Comfortable with basic Python syntax.
2 Drawing with Turtles 4 Lessons ⌄
Module Focus: Use the Turtle library to make programming highly visual and explore loops.
  • Importing libraries
  • Turtle commands (forward, right, left)
  • Changing colors and pen sizes
  • Using for loops to draw shapes
Key Concepts: LibrariesCoordinatesFor LoopsAngles
1 Meet the Turtle
Taught: Import turtle, basic movement.
Learner Lab: Draws a simple square and triangle.
Why It Matters: Introduces libraries and visual output.
Expected Deliverable: Basic geometric drawings.
2 Colorful Code
Taught: Colors, pencolor, fillcolor.
Learner Lab: Draws a colorful house.
Why It Matters: Adds creativity to code.
Expected Deliverable: A multi-colored digital drawing.
3 Looping Shapes
Taught: For loops.
Learner Lab: Uses loops to draw complex stars and circles.
Why It Matters: Saves time typing repetitive commands.
Expected Deliverable: Efficiently coded geometric art.
4 The Spirograph Project
Taught: Nested loops and slight angle changes.
Learner Lab: Generates a beautiful, complex spirograph pattern.
Why It Matters: Shows the power of mathematical coding.
Expected Deliverable: Advanced digital art piece.
🛠️ Hands-on Lab: Design a custom piece of Turtle art.
📝 Practical Assignment: Submit the Turtle Spirograph code.
💼 Commercial Application: Graphics programming basics.
🎯 Expected Outcome: Ability to use libraries and loops for visual output.
3 Game Logic and Functions 4 Lessons ⌄
Module Focus: Learn conditionals and functions to build interactive games.
  • If/Else statements
  • While loops
  • Defining custom functions
  • The random module
Key Concepts: ConditionalsWhile LoopsFunctionsRandomness
1 Making Decisions
Taught: If, elif, else.
Learner Lab: Builds a password checker.
Why It Matters: Programs need to make choices based on data.
Expected Deliverable: A script with conditional logic.
2 The Number Guessing Game
Taught: While loops and random.randint().
Learner Lab: Codes a game where the user guesses a secret number.
Why It Matters: Introduces game loops and unpredictability.
Expected Deliverable: A fully functional text game.
3 Creating Your Own Commands
Taught: Defining functions (def).
Learner Lab: Builds a trivia quiz using functions for each question.
Why It Matters: Organizes code and makes it reusable.
Expected Deliverable: Modular, organized code.
4 Final Game Project
Taught: Combining all concepts.
Learner Lab: Builds a custom text-adventure or advanced Turtle game.
Why It Matters: Proves mastery of the material.
Expected Deliverable: A complete, original Python project.
🛠️ Hands-on Lab: Build the final Python project.
📝 Practical Assignment: Submit the final project code.
💼 Commercial Application: Application logic and modular coding.
🎯 Expected Outcome: Ability to build complex scripts using logic and functions.
