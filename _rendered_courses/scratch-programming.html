CURRICULUM ARCHITECTURE

Multi-Stage Learning Journey

STEP-BY-STEP MODULES

Detailed Curriculum & Labs

1 Getting Started: Animation and Events 3 Lessons ⌄
Module Focus: Familiarize students with the Scratch interface and basic sequencing.
  • Navigating the Scratch editor
  • Adding and modifying sprites and backdrops
  • Using Motion and Looks blocks
  • Triggering code with Events
Key Concepts: Interface NavigationSequencingEventsCostumes
1 Welcome to Scratch
Taught: The layout: Stage, Sprite panel, and Block palette.
Learner Lab: Creates an account and makes a sprite move 10 steps.
Why It Matters: Knowing where things are is the first step to creating.
Expected Deliverable: Familiarity with the interface.
2 Lights, Camera, Action!
Taught: Backdrops and Looks blocks (Say, Think, Costumes).
Learner Lab: Creates a digital greeting card with changing backgrounds and text.
Why It Matters: Adds visual storytelling elements.
Expected Deliverable: A basic animation sequence.
3 Making it Go: Event Blocks
Taught: Green flag, key presses, and sprite clicking.
Learner Lab: Programs a sprite to jump when the spacebar is pressed.
Why It Matters: Allows the user to interact with the program.
Expected Deliverable: An interactive sprite.
🛠️ Hands-on Lab: Build a short interactive story featuring two characters talking.
📝 Practical Assignment: Submit the interactive story project link.
💼 Commercial Application: Basic user interaction design.
🎯 Expected Outcome: Ability to create basic interactive animations.
2 Game Logic: Loops, Conditionals, and Sensors 3 Lessons ⌄
Module Focus: Introduce the core concepts needed to turn animations into games.
  • Using loops to repeat actions forever
  • Implementing If/Then statements
  • Using Sensing blocks to detect collisions
  • Adding sound effects
Key Concepts: LoopsConditionalsSensingCollision
1 Never Stop Moving: Loops
Taught: Forever and Repeat blocks.
Learner Lab: Creates a looping background animation.
Why It Matters: Essential for continuous game mechanics (like moving clouds).
Expected Deliverable: A program with continuous loops.
2 Rules of the Game: Conditionals
Taught: If/Then blocks.
Learner Lab: Programs keyboard controls (arrow keys) to move a character.
Why It Matters: Allows the game to enforce rules (e.g., if you touch lava, you lose).
Expected Deliverable: A fully controllable character.
3 Collision Detection: Sensing
Taught: Touching color and touching sprite blocks.
Learner Lab: Builds a simple maze game where touching the walls sends you back.
Why It Matters: Allows sprites to interact with each other.
Expected Deliverable: A functional maze game.
🛠️ Hands-on Lab: Create a 'Chase' game where one sprite must catch another.
📝 Practical Assignment: Submit the Chase game project link.
💼 Commercial Application: Algorithm logic and collision detection.
🎯 Expected Outcome: Understanding of how to build basic game rules.
3 Advanced Games and Final Project 3 Lessons ⌄
Module Focus: Add advanced features like scoring and complete a final capstone game.
  • Creating and using Variables for scores
  • Broadcasting messages between sprites
  • Planning and executing a complex project
  • Debugging common Scratch issues
Key Concepts: VariablesBroadcastingGame DesignDebugging
1 Keeping Score
Taught: Variables.
Learner Lab: Adds a points system and a countdown timer to their Chase game.
Why It Matters: Makes games competitive and measurable.
Expected Deliverable: A game with win/loss states based on score.
2 Secret Messages: Broadcasting
Taught: Broadcast and receive blocks.
Learner Lab: Programs a 'Game Over' screen that appears when the timer hits zero.
Why It Matters: Allows multiple sprites to coordinate actions (like changing levels).
Expected Deliverable: Coordinated sprite behavior.
3 Capstone Creator
Taught: Project planning and independent work.
Learner Lab: Designs and codes an original game from start to finish.
Why It Matters: Develops confidence to build original ideas.
Expected Deliverable: A complete, original Scratch game.
🛠️ Hands-on Lab: Build the final capstone game.
📝 Practical Assignment: Submit the final project link and share it in the class studio.
💼 Commercial Application: State management (variables) and event broadcasting.
🎯 Expected Outcome: Ability to independently design and program a full Scratch game.
