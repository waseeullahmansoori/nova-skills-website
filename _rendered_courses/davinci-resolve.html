3.5 Node-Based Grading
Taught: Node architecture in DaVinci Resolve: Serial nodes, Parallel nodes, Layer nodes, node execution order, node labels, disabling nodes, node caching, and why node trees outperform linear layer stacks.
  • Why nodes: non-linear signal processing vs destructive layer-based adjustment stacks
  • Serial nodes (Alt/Option+S): sequential signal flow from left to right
  • Parallel nodes (Alt/Option+P): applying independent adjustments simultaneously and blending
  • Layer nodes (Alt/Option+L): priority-based blending using blending modes or keys
  • Labeling nodes with specific descriptive names (e.g. 'Exp/Bal', 'Skin', 'Look')
  • Disabling single nodes (Ctrl/Cmd+D) or all nodes (Alt/Option+D) to compare before/after steps
Learner Lab: Constructs a clean 5-node serial and parallel grading tree with descriptive labels.
Why It Matters: Organized node trees allow precise adjustments without compounding errors or muddiness.
Expected Deliverable: Complete understanding of node signal flow, node types, and labeled organization.

  • LUT stacking pitfalls: stacking multiple creative LUTs causing severe color banding and noise
  • Checking contrast consistency across dialogue cuts to avoid viewer visual fatigue
