STEP-BY-STEP MODULES

Detailed Curriculum & Labs

1 Vector Design Foundations 7 Lessons ⌄
Module Focus: Understand Illustrator's vector environment, document setup, design principles, artwork organization and fundamental drawing tools.
Key Topics Covered (18):
  • Introduction to Adobe Illustrator: role in commercial design, agency workflows, and vector industry standards
  • Raster versus vector graphics: mathematical vectors, infinite resolution independence, file-size efficiency, and print scalability
  • Illustrator interface and custom workspaces: Tools panel, Control bar, Properties panel, and docked studio panels
  • Document creation and profiles: Print, Web, Art & Illustration, canvas dimensions, orientation, and color modes
  • Artboards in Illustrator: creating, resizing, duplicating, reordering, and multi-artboard canvas architecture
  • Units, rulers, and coordinate systems: millimeters, inches, points, pixels, zero-point placement, and mathematical precision
  • Guides and grids: custom guides, Lock/Hide guides, Make Guides from shapes, Smart Guides alignment, and snap settings
  • Geometric shape tools: Rectangle, Rounded Rectangle, Ellipse, Polygon, Star, Line Segment, and live shape properties
  • Fill and stroke mechanics: Fill vs Stroke focus, stroke weights, stroke caps (Butt, Round, Projecting), and joins (Miter, Round, Bevel)
  • Color fundamentals: RGB additive color vs CMYK subtractive process color, Swatches panel, global colors, global color swatches, and color groups
  • Basic typography tools: Type Tool, Point Type vs Area Type, font selection, font size, tracking, and leading
  • Artwork organization: Layers panel, sublayers, layer color coding, grouping objects, locking, hiding, and stacking order
  • Selection tools: Selection Tool (V) bounding box, Direct Selection Tool (A) anchor manipulation, and Group Selection
  • Alignment and distribution: Align panel, Align to Selection, Align to Key Object, Align to Artboard, and Distribute Spacing
  • Object transformation: Transform panel, reference point selection, scaling, rotation, reflection, and Free Transform
  • Basic Appearance panel: understanding object appearance hierarchy and default graphic styles
  • Core commercial design principles: visual hierarchy, contrast, balance, alignment, proximity, repetition, and positive/negative space
  • File saving and preservation: native Illustrator (.ai) format, PDF compatibility, Illustrator Cloud documents, and version history
🛠️ Hands-on Lab: Construct grid-aligned geometric poster foundations; set up multi-artboard working canvases; manage global color palettes that update dynamically across multiple document shapes; balance typographic elements with geometric shapes.

2 Precision Vector Construction 9 Lessons ⌄
Module Focus: Master accurate vector construction using paths, curves, Boolean operations, object transformation and professional shape-editing techniques.
Key Topics Covered (22):
  • Path construction fundamentals: anchor points, direction lines, direction handles, and mathematical Bézier curves
  • Anchor point anatomy: smooth points (collinear handles), corner points (independent handles), open paths, and closed contours
  • The Pen Tool mastery: click-and-drag curve drafting, handle extension, maintaining smooth curve tangents, and closing paths
  • Path editing toolset: Add Anchor Point, Delete Anchor Point, Convert Anchor Point Tool, and anchor point alignment controls
  • The Curvature Tool: intuitive curve drawing, automatic smooth point generation, and double-clicking to toggle corner points
  • Anchor point optimization: the 'less is more' vector principle, eliminating redundant points, and avoiding lumpy curves
  • Shape Builder Tool: interactive click-and-drag merging, Alt/Option-click deletion of overlapping regions, and shape coloring
  • Pathfinder panel deep dive: Shape Modes (Unite, Minus Front, Intersect, Exclude) and Pathfinder operations (Divide, Trim, Merge, Crop, Outline)
  • Compound paths: combining multiple open/closed paths into a single object, Non-Zero Winding vs Even-Odd fill rules, and creating cutouts
  • Compound shapes: creating reversible, editable Boolean combinations using Alt-clicking in the Pathfinder panel
  • Clipping masks: bounding artwork visibility within container shapes, nested masks, and mask editing modes
  • Offset Path: creating mathematically parallel outer and inner offset contours for badges, borders, and stickers
  • Outline Stroke versus Offset Path: converting stroke weight into filled closed vector geometry for clean scaling and production
  • Expand versus Expand Appearance: expanding live shapes, blend effects, strokes, patterns, and dynamic appearances
  • Variable Width Tool: creating custom stroke calligraphic profiles, adjusting localized stroke thickness, and saving width profiles
  • Advanced stroke styling: dashed and dotted lines, dash/gap numerical sequencing, stroke corner joins, and arrowheads
  • Appearance panel stacking: adding multiple fills and multiple strokes to a single path, opacity blending, and live effect stacking
  • Object transformation tools: Rotate Tool, Reflect Tool (symmetry axis), Scale Tool, Shear Tool, and Transform Each with randomizing options
  • Repeat features: Radial Repeat, Grid Repeat, and Mirror Repeat for symmetrical badges, mandalas, and technical pattern layouts
  • Join and Average commands: bridging open path endpoints, averaging coordinate positions, and Path Simplify for clean geometry
  • Pixel Preview and optical alignment: aligning vector points to the pixel grid for razor-sharp digital display, and optical balance overrides
  • Vector geometry quality assurance: diagnosing unclosed paths, stray anchor points, overlapping vector artifacts, and inverted handles
🛠️ Hands-on Lab: Hand-trace intricate technical silhouettes with minimal anchor points; execute Boolean subtractions to cut precise internal holes; build multi-stroke decorative badges using the Appearance panel; construct symmetrical emblems using Reflect and Mirror Repeat.
📝 Practical Assignment: [object Object]
3 Typography & Layout Systems 8 Lessons ⌄
Module Focus: Develop typography and layout proficiency for vector posters, icon families and commercial visual communication.
Key Topics Covered (18):
  • Typography in commercial vector design: history, classifications (Serif, Sans-Serif, Slab Serif, Script, Monospaced, Display)
  • Type anatomy: baseline, x-height, cap height, ascenders, descenders, counters, serifs, and terminal nuances
  • Font pairing and hierarchy: establishing contrast between header, subheader, body copy, and micro-text callouts
  • Character panel mastery: font family, font style, font size, proportional leading, optical kerning vs metrics kerning, and tracking
  • Paragraph panel controls: left/center/right alignment, justification options, hyphens control, space before/after paragraph, and indents
  • Area Type mechanics: text container bounding, threading text between boxes, auto-sizing text frames, and text wrap around vector objects
  • Point Type versus Area Type: operational differences, avoiding accidental point-type distortion during object scaling
  • Type on Path Tool: flowing text along open curves, closed geometric paths, flip options, path alignment (Ascender, Descender, Center, Baseline)
  • Glyphs panel and OpenType features: stylistic alternates, discretionary ligatures, small caps, fractions, and glyph substitutions
  • Editable text preservation: retaining live fonts in master files, font substitution warnings, and font package dependencies
  • Text outlines (Create Outlines): converting fonts to vector paths, appropriate use cases, irreversible consequences, and archiving live copies
  • Custom lettering foundations: modifying outlined letterforms with the Direct Selection Tool, extending terminals, and custom ligature crafting
  • Vector poster grid systems: column grids, modular grids, baseline grids, golden ratio proportions, and safe printing margins
  • Layout dynamics: visual rhythm, intentional reading order (Z-pattern, F-pattern), typographic contrast, and purposeful whitespace
  • Iconography design systems: defining a master icon design specification sheet (grid, padding, live area, stroke weight family, corner radii)
  • Visual weight and optical sizing: balancing circular vs square icons, compensating for geometric area differences, and optical centering
  • Icon styles: outlined/stroke-based icons vs filled/solid-state icons, two-tone styles, and maintaining stylistic unity across a suite
  • SVG icon export standards: viewBox optimization, responsive scaling, removing unnecessary Illustrator metadata, and web developer handoff
🛠️ Hands-on Lab: Design an editorial typographic poster where type is the primary visual hero; manipulate outlined letterforms to create custom brand titles; expand preliminary icon sketches into a unified 12-icon family following strict optical and grid rules.

4 Illustration & AI-Assisted Vectors 7 Lessons ⌄
Module Focus: Create original vector illustrations using manual drawing techniques and responsibly selected generative vector tools.
Key Topics Covered (17):
  • Vector illustration fundamentals: commercial illustration briefs, editorial vs product vs advertising illustration styles
  • Concept development: moodboard curation, thumbnail sketching, and the sketch-to-vector workflow via Template layers
  • Shape simplification and visual stylization: reducing complex organic forms into bold, expressive vector silhouettes
  • Advanced curve rendering: sculpting organic vector contours, multi-segment curves, and smooth directional transitions
  • Gradients in vector illustration: Linear and Radial gradients, Gradient Annotator tool, color stops, opacity stops, and aspect ratios
  • Freeform gradients and Gradient Mesh: mesh points, mesh patches, directional mesh lines, and photorealistic vector tonal shading
  • The Blend Tool: creating smooth color transitions, specified steps for multi-line shading, specified distance, and replacing blend spines
  • Brushes panel mastery: Calligraphic brushes, Art Brushes (stretching artwork along paths), Pattern Brushes (corner/side tiles), and Scatter Brushes
  • Custom brush creation: authoring custom vector linework, textured ink strokes, stippling brushes, and non-destructive stroke styling
  • Pattern design: Pattern Options workspace, tile types (Grid, Brick by Row, Brick by Column, Hex by Column), overlap controls, and seamless repeats
  • Symbols and component reuse: dynamic symbols, Symbol Sprayer toolset, 9-slice scaling, and managing global vector component libraries
  • Adobe Firefly vector capabilities: Text to Vector Graphic engine (generating Subjects, Scenes, Icons, and Patterns via prompts)
  • Generative Shape Fill: using existing vector shapes as bounding geometry to generate detailed contextual vector artwork
  • Prompt engineering for vector artwork: specifying art styles, color palettes, vector complexity, and preventing semantic drift
  • AI vector inspection and quality control: diagnosing excess anchor points, tangled paths, open unclosed loops, and hidden raster embeds
  • Manual refinement of AI vectors: using Simplify Path, deleting phantom geometry, re-drawing warped curves, and recoloring with Global Swatches
  • Intellectual property, copyright, and Adobe Firefly commercial licensing terms, credit consumption, and client provenance documentation
🛠️ Hands-on Lab: Illustrate a stylized commercial character, scene, or botanical subject from an initial pencil sketch; blend multi-line shading profiles; generate vector concept variations with Firefly; manually reconstruct and optimize generated vector contours to achieve clean studio geometry.

5 Commercial Artwork & Production 8 Lessons ⌄
Module Focus: Produce commercial multi-artboard artwork and prepare reliable digital and print-ready deliverables.
Key Topics Covered (18):
  • Commercial advertising and marketing design briefs: interpreting technical specifications, brand standards, and delivery deadlines
  • Physical print dimensions versus digital screen pixels: ISO A-series (A4, A5), US standard paper sizes, and digital banner formats
  • Multi-artboard commercial production: coordinating coordinated marketing suites (posters, brochures, flyers, social assets) in one file
  • Prepress technicalities: trim lines, safe content margins, and 3mm (0.125 in) bleed setup for borderless edge-to-edge printing
  • Printer marks: trim marks, bleed marks, registration marks, color bars, and page information
  • Color management for print production: converting RGB to CMYK, gamut warnings, color profile assignment (e.g. Coated FOGRA39, US Web Coated)
  • Spot colors and process printing: Spot Color swatches, Pantone Matching System (PMS) library awareness, and spot-to-process conversions
  • Overprint and trapping fundamentals: Overprint Fill, Overprint Stroke, Knockout preview, and avoiding misregistration gaps
  • Black printing rules: pure 100% K black for crisp text vs Rich Black (C:60 M:40 Y:40 K:100) for deep, saturated background solids
  • Transparency and Flattening: transparency blend spaces (CMYK vs RGB), Flattener Preview panel, and raster/vector balance controls
  • Image asset management: Links panel, Linked vs Embedded images, checking effective PPI (minimum 300 PPI for print), and updating missing links
  • Font management and prepress compliance: checking missing fonts, keeping live text in master files, and outlining type only for final print copies
  • File packaging (File > Package): automated collection of fonts, linked imagery, color profiles, and generation of packaging report
  • Digital vector export: Export for Screens workspace, SVG export settings (SVG 1.1 vs SVG Tiny, styling internal CSS vs presentation attributes)
  • PDF creation for print: Adobe PDF presets (High Quality Print, Press Quality, PDF/X-1a, PDF/X-4), standard compliance, and font embedding
  • Adobe Acrobat inspection and preflight: verifying separations, checking trim/bleed boxes, measuring ink density, and visual proofing
  • Professional source-file handover standards: 8 standard logical layer groups, descriptive naming, purging unused swatches and symbols
  • Client delivery package architecture: organizing 01_Editable_AI, 02_Print_PDF, 03_SVG_Assets, 04_Digital_Previews, 05_Linked_Assets, 06_Documentation
🛠️ Hands-on Lab: Set up multi-artboard commercial campaigns with 3mm bleeds; soft-proof spot colors and Rich Black; package a complete production file with fonts and linked imagery; preflight exported PDF/X files in Adobe Acrobat.
