STEP-BY-STEP MODULES

Detailed Curriculum & Labs

1 Digital Measurement Strategy & Planning 4 Lessons ⌄
Module Focus: Translate high-level business objectives into an implementable digital measurement framework, defining events, parameters, key events, and governance rules.
Key Topics Covered (16):
  • Digital analytics fundamentals & business-first measurement thinking: why measurement drives strategic growth
  • Website and marketing objectives: defining business KPIs versus vanity metrics (impressions vs. qualified leads/revenue)
  • Measurement strategy & digital analytics ecosystem overview: understanding user touchpoints across web and app
  • GA4 event-based data model: comparing event-driven architecture to legacy session/pageview systems
  • Events and event parameters: structure, data types, and value hierarchies
  • Users and active users: 1-day, 7-day, and 28-day active user metrics and engagement rate definition
  • Sessions, engagement metrics, and session duration: how GA4 defines session starts and engagement time
  • Traffic sources, channels, and Default Channel Grouping rules in GA4
  • Key events and conversions: defining high-value user milestones (lead forms, signups, transactions)
  • Lead-generation measurement vs. E-commerce measurement fundamentals
  • Customer journey analysis, funnel stages, and touchpoint interaction mapping
  • Attribution fundamentals, attribution model limitations, and cross-channel measurement concepts
  • Measurement framework development: business questions, metrics, data sources, and technical requirements
  • Event naming conventions & event taxonomy: snake_case rules, reserved prefixes, and character limits
  • Data collection requirements and measurement specification documents (Measurement Plan)
  • Marketing and stakeholder reporting goals: aligning tracking specifications with executive decision needs
🛠️ Hands-on Lab: Designing a comprehensive Measurement Plan spreadsheet for an e-commerce or lead generation website, mapping 10 business questions to specific GA4 events and parameters.
📝 Practical Assignment: End-to-End Business Measurement Plan (Google Sheets / PDF) detailing business objectives, user journey, KPI framework, event inventory, parameter taxonomy, key event criteria, and measurement validation checklist.
2 Google Analytics 4 Implementation 4 Lessons ⌄
Module Focus: Configure a production-ready GA4 property, data streams, custom dimensions, data retention settings, and verify incoming telemetry using Realtime and DebugView.
Key Topics Covered (17):
  • Google Analytics ecosystem, GA4 account structure, property setup, and access permission hierarchies (Admin, Editor, Marketer, Viewer)
  • Web data streams, Measurement IDs (G-XXXXXXXXXX), and stream configuration options
  • Google tag fundamentals: gtag.js architecture and implementation approaches (direct installation vs. Google Tag Manager)
  • GA4 implementation through Google Tag Manager: Google tag configuration tag vs. GA4 Event tags
  • Enhanced measurement events: page_view, scroll, outbound clicks, site search, video engagement, file downloads
  • Automatically collected events vs. Recommended events vs. Custom events: when and how to choose each category
  • Recommended event implementation: view_item, select_content, generate_lead, sign_up, purchase
  • Event parameters and event parameter registration: creating Custom Dimensions (event-scoped and user-scoped) and Custom Metrics
  • Data retention settings: extending event data retention from 2 months to 14 months
  • Data filters: defining internal IP traffic filters and developer traffic filters
  • Referral exclusions & unwanted referrals: identifying payment gateway loops and third-party auth domains
  • Key event configuration: designating high-value events as Key Events in GA4 Admin
  • GA4 Key Events versus Google Ads conversions: understanding the distinction, counting methods, and import mechanics
  • Event values and counting concepts: once per event vs. once per session counting rules
  • User properties and custom audience configuration: building behavioral audiences for remarketing and reporting
  • Realtime reports, GA4 DebugView, event testing, verification, and implementation troubleshooting
  • E-commerce event awareness (view_item_list, add_to_cart, begin_checkout, purchase) and data quality reviews
🛠️ Hands-on Lab: Setting up a live GA4 property, creating custom dimensions for event parameters, adjusting data retention to 14 months, creating an internal traffic filter, and validating event arrival in DebugView.
📝 Practical Assignment: GA4 Property Configuration & Validation Record: documented setup of property, web data stream, 5 custom events, custom dimensions, key events, and DebugView verification evidence.
3 Google Tag Manager & Event Tracking 4 Lessons ⌄
Module Focus: Master Google Tag Manager to configure tags, triggers, variables, and dataLayer events, thoroughly testing tracking sequences before publishing.
Key Topics Covered (18):
  • Google Tag Manager fundamentals: GTM architecture vs. hardcoded scripts, agility, governance, and site speed benefits
  • GTM accounts, containers, container IDs (GTM-XXXXXXX), and installation on websites (<head> and <body> snippets)
  • GTM Workspaces, version control, user permissions, and collaborative publishing workflows
  • GTM building blocks: Tags (what to do), Triggers (when to do it), and Variables (information needed)
  • Built-in variables (Page URL, Click Classes, Click ID, Form Element) vs. User-defined variables (Constant, Lookup Table, Data Layer Variable)
  • Google tag configuration in GTM: setting the Measurement ID and configuration parameters
  • GA4 Event tags: mapping event names and event parameters to GTM triggers and variables
  • Trigger types and evaluation: Page View, DOM Ready, Window Loaded
  • Click triggers: All Elements vs. Just Links, CSS selector targeting, and button interaction tracking
  • Form submission tracking: Form Submit trigger, element visibility triggers, and AJAX/custom submission challenges
  • Scroll depth tracking and custom event triggers
  • Data Layer fundamentals: understanding window.dataLayer array and dataLayer.push() syntax
  • Data Layer variables: extracting dynamic values (transaction IDs, lead values, user roles) from the data layer
  • Event parameters populated from Data Layer variables
  • Debugging tag behavior: GTM Preview Mode, Tag Assistant connection, and event timeline inspection
  • Tag firing sequences, trigger exceptions, blocking triggers, and duplicate event prevention
  • Understanding the measurement pipeline: User action -> GTM Trigger -> Tag executes -> GA4 receives -> GA4 processes -> Key event designated
  • Container export/import, version naming conventions, release notes, and tag governance best practices
🛠️ Hands-on Lab: Building a complete GTM container with Google Tag, 4 GA4 Event tags (button click, contact form submission, file download, outbound link), testing via Preview Mode, and publishing version 1.0.
📝 Practical Assignment: GTM Container & Event Implementation Package: exported container JSON, setup documentation, trigger logic specifications, and Tag Assistant preview mode verification screenshots.
4 Measurement Quality, Privacy & Governance 4 Lessons ⌄
Module Focus: Audit tracking implementations for data discrepancies, enforce UTM governance, avoid PII collection, and configure consent-aware measurement using Google Consent Mode.
Key Topics Covered (17):
  • Measurement quality fundamentals: reliability, consistency, and completeness of digital telemetry
  • Event naming governance and taxonomy enforcement: preventing lowercase/uppercase fragmentation and duplicate events
  • Troubleshooting tracking failures: missing events, overcounting, incorrect triggers, and parameter mismatches
  • Internal traffic management and IP filtering verification
  • Campaign tracking & UTM parameter governance: utm_source, utm_medium, utm_campaign, utm_term, utm_content
  • Standardizing UTM taxonomy: case-sensitivity, naming conventions, UTM builder spreadsheets, and preventing attribution loss
  • Referral traffic issues, self-referrals, and payment gateway attribution preservation
  • Cross-domain measurement fundamentals: linking client IDs across multiple domains and preserving session continuity
  • Privacy and consent-aware analytics: GDPR, ePrivacy Directive, California CPRA, and India's DPDP Act implications
  • Google Consent Mode fundamentals: how consent signals adjust tag behavior (not a replacement for a consent banner)
  • Consent types and parameters: analytics_storage, ad_storage, ad_user_data, ad_personalization
  • Consent initialization in GTM: default consent state vs. updated consent state
  • Basic Consent Mode vs. Advanced Consent Mode: cookieless pings and behavioral modeling concepts
  • Consent Management Platforms (CMPs) overview: Cookiebot, OneTrust, Usercentrics integration patterns
  • Consent signal debugging using GTM Preview Mode and Tag Assistant
  • Strict prohibition of Personally Identifiable Information (PII) in GA4: emails, phone numbers, full names; data redaction tools
  • Data retention policies, user deletion requests, access governance, and tracking QA audit methodologies
🛠️ Hands-on Lab: Auditing a live website for tracking bugs, duplicate tags, and unmasked PII; creating a standardized enterprise UTM governance spreadsheet; testing Consent Mode tag behavior under denied vs. granted states.
📝 Practical Assignment: GA4/GTM Tracking Quality & Privacy Audit Report: evaluation of a website's measurement setup, identifying tracking errors, UTM inconsistencies, consent readiness, and remediation steps with severity ratings.
5 GA4 Analysis, Explorations & Reporting 3 Lessons ⌄
Module Focus: Extract actionable business intelligence from GA4 data using Standard Reports, custom Funnel Explorations, Path Explorations, and user segmentation.
Key Topics Covered (16):
  • GA4 interface and navigation: Home, Reports workspace, Explore workspace, and Advertising workspace
  • Standard reports vs. custom reports: Reports snapshot, Realtime reporting, and report customization
  • Acquisition reporting: User Acquisition (first-touch channel) versus Traffic Acquisition (session-level channel)
  • Default Channel Groups: Organic Search, Paid Search, Direct, Organic Social, Paid Social, Email, Referral
  • Engagement reporting: Pages and screens, Landing page report, Events report, and Key events report
  • User metrics vs. Session metrics: Active users, New users, Sessions, Engaged sessions, Engagement rate, Average engagement time
  • Traffic source analysis: evaluating organic vs. paid campaigns, bounce/engagement rate correlations, and landing page effectiveness
  • Audience analysis: demographics, geography, technology devices, and custom audience behavior
  • GA4 Explorations deep-dive: Free-form explorations, nested dimensions, metric calculations, and data visualization types
  • Funnel Explorations: open vs. closed funnels, step progression, drop-off rate calculation, and abandonment bottleneck identification
  • Path Explorations: forward and backward user journey mapping from key event milestones
  • Segments and comparisons: creating user segments, session segments, and event segments for comparative analysis
  • Attribution interpretation: Data-Driven Attribution (DDA) vs. Last-Click model differences and conversion credit distribution
  • Reporting identity concepts: Blended, Observed, Device-based; understanding Google Signals, user ID, and device ID
  • Data limitations: data thresholding, orange warning icons, sampling limits, and cardinality management
  • Interpreting behavioral patterns: translating analytical findings into prioritized, testable business optimization recommendations
🛠️ Hands-on Lab: Building a multi-step checkout/lead funnel exploration, creating a backward path exploration from lead submission, and segmenting mobile vs. desktop user engagement.
📝 Practical Assignment: GA4 Website Performance Analysis & Funnel Diagnostic: executive analytical report with 5 core findings, funnel drop-off diagnostics, channel acquisition analysis, and 5 data-backed optimization recommendations.
6 Looker Studio & Business Dashboards 3 Lessons ⌄
Module Focus: Design interactive, stakeholder-ready business intelligence dashboards in Looker Studio connecting live GA4 data to provide executive decision support.
Key Topics Covered (14):
  • Business dashboard fundamentals: purpose, audience segmentation (executives, marketers, operational teams), and reporting cadences
  • Stakeholder information needs: identifying core questions, avoiding dashboard clutter, and choosing the right KPIs
  • Looker Studio interface, workspace setup, canvas formatting, themes, and branding customization
  • Data source connections: connecting Looker Studio to Google Analytics 4 via native connector; connecting Google Sheets
  • Dimensions (categorical data) and Metrics (quantitative data) in Looker Studio
  • Visual component mastery: Scorecards with comparison indicators, Time-series charts, Bar/Column charts, Pie/Donut charts, and Data tables with heatmaps
  • Interactive controls: Date range selectors, Dimension drop-down filters, Search boxes, and Cross-filtering interactions
  • Basic calculated fields: combining metrics, conversion rates (Key Events / Sessions), and custom naming
  • Dashboard information hierarchy: executive summary KPIs at the top, trendlines in the middle, granular breakdown tables at the bottom
  • Data storytelling & visual clarity: color harmony, readable typography, context benchmarks, and annotations
  • Interpreting trends: separating seasonal shifts from marketing campaign effects
  • Dashboard sharing permissions: View vs. Edit access, embedding reports, scheduled email delivery, and PDF export
  • Dashboard maintenance, connector troubleshooting, GA4 API quota limits (tokens per project/hour), and optimization strategies
  • Final Capstone Portfolio presentation: assembling all 4 course deliverables into a professional showcase for employment and freelancing
🛠️ Hands-on Lab: Building an end-to-end 2-page marketing performance dashboard in Looker Studio with scorecards, channel acquisition bar charts, landing page performance table, date range picker, and channel filter.
📝 Practical Assignment: Stakeholder-Ready Marketing Performance Dashboard (Looker Studio link + PDF executive brief) featuring 5 core scorecards, channel performance trends, conversion breakdown, and executive summary notes.
