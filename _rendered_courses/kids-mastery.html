STEP-BY-STEP MODULES

Detailed Curriculum & Labs

1 Visual Coding Adventures with Scratch 4 Lessons ⌄
Module Focus: Introduce programming logic through intuitive, drag-and-drop blocks.
  • How to make characters move and speak
  • Using loops to repeat actions
  • Making decisions with if/then blocks
  • Creating a scoring system with variables
Key Concepts: SequencingLoopsConditionalsVariables
1 Meet Your Sprite: Movement & Animation
Taught: Basic sequencing and event triggers (Green Flag).
Learner Lab: Makes a cat walk across the screen and meow.
Why It Matters: It’s the foundation of making things happen on a computer.
Expected Deliverable: A simple interactive animation.
2 Looping Around: Repeating Actions
Taught: Forever and repeat loops.
Learner Lab: Creates a dance party animation with repeating moves.
Why It Matters: Saves time by not having to snap the same blocks over and over.
Expected Deliverable: A continuous, looping animation.
3 Making Choices: Conditionals
Taught: If-then-else statements and sensing blocks.
Learner Lab: Builds a simple game where a character avoids falling objects.
Why It Matters: Allows games to react to player inputs or collisions.
Expected Deliverable: A playable mini-game.
4 Keeping Score: Variables
Taught: Creating and changing variables.
Learner Lab: Adds a points system and a timer to the mini-game.
Why It Matters: Essential for tracking game progress and scores.
Expected Deliverable: A complete, scorable Scratch game.
🛠️ Hands-on Lab: Build a custom interactive story or game from scratch.
📝 Practical Assignment: Submit the link to a completed Scratch game with at least one variable and one loop.
💼 Commercial Application: Understanding game mechanics and user interaction.
🎯 Expected Outcome: Comfortable with basic programming logic using visual blocks.
2 Drawing with Code: Python Turtle 4 Lessons ⌄
Module Focus: Transition from visual blocks to typing real code by drawing shapes.
  • Typing Python commands
  • Understanding coordinates and angles
  • Using loops in Python
  • Creating digital art
Key Concepts: SyntaxCoordinatesIterationRandomness
1 Hello Python: Moving the Turtle
Taught: Basic syntax, forward/backward commands.
Learner Lab: Writes code to make the turtle draw a square.
Why It Matters: Introduces text-based syntax in a highly visual way.
Expected Deliverable: A basic Python script that draws a shape.
2 Colors and Pen Sizes
Taught: Changing attributes of the turtle.
Learner Lab: Draws a colorful, thick-lined star.
Why It Matters: Shows how code controls visual styling.
Expected Deliverable: A colorful digital drawing.
3 Python Loops for Art
Taught: For loops in Python.
Learner Lab: Uses a loop to draw a complex spiral pattern.
Why It Matters: Demonstrates the power of iteration in text coding.
Expected Deliverable: A geometric spiral generated by code.
4 Turtle Race Game
Taught: Random module and coordinate positioning.
Learner Lab: Codes a race between different colored turtles.
Why It Matters: Introduces unpredictability and basic game mechanics in Python.
Expected Deliverable: A fun, automated race simulation.
🛠️ Hands-on Lab: Create a unique piece of digital art using loops and colors.
📝 Practical Assignment: Submit a Python script that draws a recognizable object (like a house or car).
💼 Commercial Application: Algorithmic thinking and basic scripting.
🎯 Expected Outcome: Ability to write simple Python scripts independently.
3 Building Your First Website 4 Lessons ⌄
Module Focus: Learn the basics of how web pages are built using HTML and CSS.
  • Structuring a page with HTML tags
  • Adding images and links
  • Styling with CSS colors and fonts
  • Publishing a simple page
Key Concepts: TagsAttributesStylingLayout
1 The Skeleton: HTML Basics
Taught: Headings, paragraphs, and lists.
Learner Lab: Writes an HTML page about their favorite hobby.
Why It Matters: Every website in the world uses these fundamental building blocks.
Expected Deliverable: A structured, text-only web page.
2 Adding Pictures and Links
Taught: Img and Anchor tags.
Learner Lab: Adds photos and links to other sites on their hobby page.
Why It Matters: Makes the web interactive and visually interesting.
Expected Deliverable: A multimedia HTML page.
3 The Paintbrush: CSS Basics
Taught: Selectors, colors, and fonts.
Learner Lab: Styles their hobby page with their favorite colors and fonts.
Why It Matters: Turns a boring document into a beautiful design.
Expected Deliverable: A styled web page.
4 Designing a Portfolio Layout
Taught: Basic layout techniques (margins, padding).
Learner Lab: Creates a mini-portfolio to showcase their Scratch and Turtle projects.
Why It Matters: Helps organize content neatly on the screen.
Expected Deliverable: A complete, personal web page layout.
🛠️ Hands-on Lab: Build a multi-section web page dedicated to a favorite topic.
📝 Practical Assignment: Submit the HTML/CSS code for a fully styled personal web page.
💼 Commercial Application: Foundations of frontend web development.
🎯 Expected Outcome: Ability to create and style simple web pages.
4 3D Design and AI Magic 4 Lessons ⌄
Module Focus: Explore spatial design and the creative potential of AI tools.
  • Navigating 3D space
  • Combining shapes to make complex models
  • Using AI for brainstorming ideas safely
  • Creating AI-assisted stories
Key Concepts: 3D ModelingSpatial ReasoningPromptingAI Collaboration
1 Welcome to the 3D World
Taught: Moving, rotating, and scaling shapes in Tinkercad.
Learner Lab: Builds a simple 3D house.
Why It Matters: Develops spatial reasoning for engineering and design.
Expected Deliverable: Familiarity with 3D workspace controls.
2 Designing for the Real World
Taught: Grouping shapes and creating holes.
Learner Lab: Designs a custom name tag or keychain.
Why It Matters: Essential techniques for creating custom, printable objects.
Expected Deliverable: A complete 3D model ready for printing.
3 Talking to AI Safely
Taught: How to ask good questions (prompts) to an AI.
Learner Lab: Uses a kid-safe AI to generate ideas for a new game.
Why It Matters: Prompt engineering is a key skill for the future.
Expected Deliverable: A brainstormed document of ideas.
4 AI Storytelling
Taught: Collaborating with AI to write a narrative.
Learner Lab: Writes an interactive story where AI helps create the plot twists.
Why It Matters: Shows how technology can boost, not replace, human creativity.
Expected Deliverable: A co-authored creative story.
🛠️ Hands-on Lab: Design a 3D character and use AI to write its backstory.
📝 Practical Assignment: Submit a screenshot of the 3D model and the AI-assisted story.
💼 Commercial Application: Product design and creative writing.
🎯 Expected Outcome: Basic competence in 3D modeling and safe AI prompting.
5 Capstone: The Master Creator Showcase 4 Lessons ⌄
Module Focus: Combine all learned skills to build one large, impressive final project.
  • Project planning and management
  • Debugging complex issues
  • Presenting work confidently
  • Reflecting on the learning journey
Key Concepts: Project ManagementDebuggingPresentationReflection
1 Planning Your Masterpiece
Taught: Storyboarding and wireframing.
Learner Lab: Sketches out their final project (game, website, or 3D world).
Why It Matters: Big projects need a solid plan to succeed.
Expected Deliverable: A detailed project blueprint.
2 Building and Coding
Taught: Independent problem solving.
Learner Lab: Spends the session actively building their project.
Why It Matters: Develops resilience and self-reliance.
Expected Deliverable: A working prototype of the project.
3 Testing and Polishing
Taught: Peer review and debugging.
Learner Lab: Has a classmate or parent test the project, then fixes bugs.
Why It Matters: Feedback improves the final product significantly.
Expected Deliverable: A polished, bug-free final project.
4 The Showcase Presentation
Taught: Public speaking and demonstration skills.
Learner Lab: Records a short video or gives a live demo of their creation.
Why It Matters: Being able to explain your work is as important as building it.
Expected Deliverable: A final presentation celebrating their achievements.
🛠️ Hands-on Lab: Build the final capstone project.
📝 Practical Assignment: Submit the final project files and presentation video.
💼 Commercial Application: Product launch and demonstration.
🎯 Expected Outcome: A comprehensive portfolio piece demonstrating all course skills.
