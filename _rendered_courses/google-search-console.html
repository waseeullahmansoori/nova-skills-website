CURRICULUM ARCHITECTURE

Multi-Stage Learning Journey

STEP-BY-STEP MODULES

Detailed Curriculum & Labs

1 Setup, Verification & Search Console Fundamentals 5 Lessons ⌄
Module Focus: Establish property ownership, configure user permissions, navigate the Search Console interface, and conduct an initial property-health baseline audit.
Key Topics Covered (5):
  • Google Search Console fundamentals: the official bridge between Google's indexing system and webmasters; why GSC is essential for modern organic search visibility
  • Domain properties versus URL-prefix properties: DNS-level verification vs. protocol/subdomain-specific scoping; choosing the right property type for your website architecture
  • Ownership verification methods: DNS TXT records, HTML file upload, HTML tag injection, Google Tag Manager container, and Google Analytics linking; managing verification risks
  • Property settings, access management, and permission tiers: Owner (Full/Delegated), Full User, and Restricted User permissions; security best practices for agency and client access
  • Search Console dashboard navigation and initial property-health checklist: overview tab, notifications center, security & manual actions alerts, and baseline configuration review
🛠️ Hands-on Lab: Setting up or inspecting an authorized Search Console property, verifying ownership via preferred methods, configuring user access roles, and documenting an initial 10-point property health checklist.
📝 Practical Assignment: Search Console Property Setup & Health Baseline Checklist (Google Sheets / PDF) confirming property scoping, verification method, permission audit, and initial health observations.
2 Indexing, Crawling & URL Diagnostics 6 Lessons ⌄
Module Focus: Inspect Google's crawling and indexing pipelines, evaluate sitemaps, interpret indexing exclusions, and diagnose URL status using the URL Inspection tool.
Key Topics Covered (6):
  • Google's crawling, indexing, and serving fundamentals: the distinction between discovery, crawl requests, page processing, indexing eligibility, and search serving
  • XML sitemaps and sitemap submission: standard XML sitemaps, sitemap index files, best practices, submission workflows, and reading sitemap processing status and error codes
  • Page indexing reports and exclusion reasons: deep dive into 'Discovered - currently not indexed', 'Crawled - currently not indexed', 'Excluded by ‘noindex’ tag', 'Page with redirect', and 'Soft 404'
  • URL Inspection tool mastery: retrieving live Google index status, inspecting referring pages, crawl timestamps, user-agent details, HTTP response codes, and rendering screenshots
  • Canonical URL observations and duplicate-content diagnostics: User-declared canonical vs. Google-selected canonical; diagnosing mismatches, canonical overrides, and parameter sprawl
  • Identifying crawl-discovery issues and fix validation: requesting re-indexing, monitoring issue validation cycles, and distinguishing diagnostic findings from developer code fixes
🛠️ Hands-on Lab: Running 5 target URLs through the URL Inspection tool, comparing user vs. Google-selected canonicals, categorizing indexing exclusions from the Page Indexing report, and drafting diagnostic tickets.
📝 Practical Assignment: Indexing Issue Register & URL Diagnostic Audit (Google Sheets / PDF) categorizing at least 5 distinct URL indexing issues with category, technical evidence, severity priority, and recommended remediation.
3 Search Performance Analysis & SEO Opportunities 7 Lessons ⌄
Module Focus: Analyze organic search telemetry—queries, pages, impressions, clicks, CTR, and average position—to uncover high-intent keyword opportunities and optimize CTR.
Key Topics Covered (7):
  • Understanding core search metrics: Clicks (user visits), Impressions (search results viewed), Click-Through Rate (CTR = Clicks / Impressions), and Average Position (mean top ranking)
  • Query-level and page-level performance analysis: evaluating top organic search queries, landing page performance, and query-to-page alignment
  • Segmentation dimensions: analyzing performance by Countries (geographic demand), Devices (desktop vs. mobile vs. tablet), Dates (seasonality), and Search Appearance (rich results, snippets)
  • Period comparison and trend analysis: comparing 28-day, 3-month, and year-over-year performance; identifying rising queries, decaying keywords, and seasonal search shifts
  • Identifying high-impression, low-CTR opportunities: spotting pages ranking on page 1 with substandard CTR; title tag and meta description optimization strategies to capture clicks
  • Interpreting branded versus non-branded search patterns: separating brand navigation queries from unbranded discovery traffic to evaluate true organic acquisition health
  • Exporting Search Console data: downloading query and page reports to Google Sheets for advanced filtering, pivot tables, and statistical ranking distributions
🛠️ Hands-on Lab: Applying regex filters in GSC Performance report to isolate non-branded questions, exporting query data to Google Sheets, and building a high-impression low-CTR opportunity matrix.
📝 Practical Assignment: Organic Search Performance & Keyword Opportunity Report (Google Sheets / PDF) highlighting top 10 winning queries, 5 decaying pages, and 5 high-impression low-CTR optimization opportunities with revised titles and snippets.
4 Technical Monitoring & Reporting 7 Lessons ⌄
Module Focus: Evaluate page experience and technical quality signals, interpret Core Web Vitals, monitor structured data enhancements, and construct automated SEO reporting tables.
Key Topics Covered (7):
  • Core Web Vitals report interpretation: Largest Contentful Paint (LCP), Interaction to Next Paint (INP), and Cumulative Layout Shift (CLS) in Search Console
  • PageSpeed Insights diagnostic integration: understanding field data (Chrome User Experience Report / CrUX) vs. lab data (Lighthouse); identifying render-blocking scripts and layout shifts
  • HTTPS, mobile usability history, and page experience monitoring: verifying security protocols, mixed content issues, and site-wide HTTPS compliance
  • Structured data enhancement reports: inspecting schema markups (Articles, Breadcrumbs, FAQs, Products, Sitelinks Searchbox) and resolving invalid item warnings
  • Issue validation and monitoring history: initiating fix validation in GSC, tracking Google's re-crawl status, and verifying resolution timelines
  • Building technical reporting tables and charts in Google Sheets: creating monthly technical health dashboards with conditional formatting and severity tracking
  • Looker Studio SEO dashboard introduction: connecting Google Search Console connector to Looker Studio for executive automated reporting
🛠️ Hands-on Lab: Auditing a website's Core Web Vitals status in GSC, running PageSpeed diagnostic tests on flagged URLs, inspecting structured data warnings, and building an automated Google Sheets technical tracker.
📝 Practical Assignment: Technical SEO Monitoring Dashboard & Issue-Priority Register (Google Sheets / Looker Studio) tracking Core Web Vitals URLs, HTTPS status, schema validation results, and categorized developer tickets.
5 AI Search Reporting, Analysis & Action Planning 10 Lessons ⌄
Module Focus: Analyze Google Generative AI Search Performance reports, evaluate AI Overviews impressions and limitations, and synthesize all diagnostic data into a 30-day SEO action plan.
Key Topics Covered (10):
  • Introduction to Google Search generative AI visibility: how generative AI features (AI Overviews and AI Mode) display synthesized summaries in Google Search results
  • Understanding the Generative AI Performance report in Search Console: background of the June 2026 introduction and August 31, 2026 worldwide rollout; eligibility criteria and impression thresholds
  • AI Overviews and AI Mode visibility reporting: identifying queries and landing pages cited or featured within generative AI summaries
  • Understanding eligible dimensions: analyzing AI Search data across pages, countries, devices, and dates
  • Interpreting AI impressions, reporting limitations, and data availability: why individual properties may show zero data; understanding that GSC does NOT provide separate AI clicks, CTR, average rank position, or prompt logs
  • Generative AI reporting for Google Discover: overview of AI features in Discover feeds and differences from Search performance
  • Traditional Search performance versus AI-feature reporting: comparing standard web search metrics against generative AI impression volume; avoiding manufactured ranking metrics
  • Data exports, anomaly investigation, and evidence-based interpretation: auditing unexpected traffic shifts, AI summary inclusion drops, and data discrepancies
  • Preparing client-ready SEO reporting summaries: synthesizing technical diagnostics, keyword wins, and AI visibility into executive-level narratives
  • Building a prioritized 30-day monitoring and improvement plan: structuring weekly milestones for crawl fixes, CTR tests, Core Web Vitals collaboration, and monthly re-audits
🛠️ Hands-on Lab: Analyzing Generative AI Performance data (or an explicitly labeled illustrative training dataset), identifying cited pages, documenting data limitations, and authoring a 30-day SEO action plan.
📝 Practical Assignment: Final Capstone Deliverable: Google Search Console SEO Audit & 30-Day Visibility Improvement Plan synthesizing property setup, indexing register, search opportunities, AI observations, and weekly milestones.
