CURRICULUM ARCHITECTURE

STEP-BY-STEP MODULES

Detailed Curriculum & Labs

1 From Blocks to Text: Introduction to Python 4 Lessons ⌄
Module Focus: Bridge the gap between visual coding and text-based programming.
  • How Python compares to Scratch
  • Using the print() and input() functions
  • Understanding variables and data types
  • Basic math operations in Python
Key Concepts: Print/InputVariablesData TypesArithmetic
1 Saying Hello to Python
Taught: The print function and basic strings.
Learner Lab: Writes their first 'Hello World' and prints a custom message.
Why It Matters: It's the first step to making the computer talk to you in text.
Expected Deliverable: A script that outputs text to the console.
2 Remembering Things: Variables
Taught: Strings, integers, and assigning values.
Learner Lab: Creates variables for a character's name, age, and power level.
Why It Matters: Variables are the memory of your program.
Expected Deliverable: A script that prints dynamic sentences using variables.
3 Talking Back: User Input
Taught: The input() function.
Learner Lab: Builds a 'Mad Libs' style story generator.
Why It Matters: Makes programs interactive.
Expected Deliverable: An interactive story that changes based on user input.
4 Computer Math
Taught: Basic arithmetic operators (+, -, *, /).
Learner Lab: Builds a simple tip calculator.
Why It Matters: Computers are excellent calculators.
Expected Deliverable: A functional mathematical script.
🛠️ Hands-on Lab: Write a script that asks for user details and performs a calculation.
📝 Practical Assignment: Submit the Mad Libs generator script.
💼 Commercial Application: Basic data input and processing.
🎯 Expected Outcome: Comfortable with basic Python syntax and I/O.
2 Python Logic: Making Decisions and Looping 4 Lessons ⌄
Module Focus: Teach the program how to make choices and repeat tasks efficiently.
  • If, elif, and else statements
  • Comparison operators
  • While loops and For loops
  • Building simple text games
Key Concepts: ConditionalsIndentationWhile LoopsFor Loops
1 Making Choices: If/Else
Taught: Conditional statements and indentation.
Learner Lab: Creates a password checking program.
Why It Matters: Allows the program to react differently based on conditions.
Expected Deliverable: A script with basic branching logic.
2 More Choices: Elif and Conditions
Taught: Multiple conditions and logical operators (and, or).
Learner Lab: Builds a grade calculator (A, B, C, etc.).
Why It Matters: Handles complex decision trees.
Expected Deliverable: A script with complex conditional logic.
3 Repeating Stuff: While Loops
Taught: While loops and avoiding infinite loops.
Learner Lab: Builds a simple number guessing game.
Why It Matters: Keeps a game running until the user quits.
Expected Deliverable: An interactive loop-based game.
4 Iterating: For Loops
Taught: For loops and the range() function.
Learner Lab: Creates a countdown timer and a multiplication table generator.
Why It Matters: Great for counting and repeating a specific number of times.
Expected Deliverable: Scripts that use bounded iteration.
🛠️ Hands-on Lab: Combine loops and conditionals to build a Rock-Paper-Scissors game.
📝 Practical Assignment: Submit the completed Rock-Paper-Scissors Python script.
💼 Commercial Application: Algorithm design and control flow.
🎯 Expected Outcome: Ability to write programs with complex logic and loops.
3 Setting Up Shop: VS Code and HTML Basics 4 Lessons ⌄
Module Focus: Introduce professional developer tools and the foundation of web pages.
  • Navigating VS Code
  • Understanding file structures
  • Writing standard HTML5
  • Structuring a web document
Key Concepts: IDE usageHTML tagsFile linkingDocument Structure
1 Meet VS Code
Taught: Installing VS Code, creating folders, and making files.
Learner Lab: Sets up a project workspace and creates their first .html file.
Why It Matters: This is the actual tool professional developers use.
Expected Deliverable: A working local development environment.
2 The HTML Skeleton
Taught: <html>, <head>, <body>, and <title> tags.
Learner Lab: Writes a valid HTML5 boilerplate document.
Why It Matters: Every web page needs this structure to work properly.
Expected Deliverable: A blank but valid web page.
3 Adding Content: Text and Headings
Taught: <h1> to <h6>, <p>, and list tags.
Learner Lab: Builds an informational page about their favorite animal.
Why It Matters: Organizes text information clearly.
Expected Deliverable: A text-heavy, structured web page.
4 Media and Navigation
Taught: <img> and <a> tags.
Learner Lab: Adds photos and links to a second HTML page.
Why It Matters: Connects pages together and adds visual appeal.
Expected Deliverable: A linked, two-page mini-website.
🛠️ Hands-on Lab: Build a two-page interlinked website with text and images.
📝 Practical Assignment: Submit the HTML files for the two-page site.
💼 Commercial Application: Frontend web architecture.
🎯 Expected Outcome: Comfortable using an IDE and writing raw HTML.
4 Styling the Web: Introduction to CSS 4 Lessons ⌄
Module Focus: Learn how to make plain HTML websites look professional and colorful.
  • Linking CSS to HTML
  • CSS syntax and selectors
  • Colors, fonts, and borders
  • Basic page layout
Key Concepts: CSS SyntaxSelectorsTypographyBox Model
1 Adding Some Style
Taught: Inline, internal, and external CSS.
Learner Lab: Creates a style.css file and links it to their HTML.
Why It Matters: Separating style from structure makes coding easier.
Expected Deliverable: A successfully linked CSS file.
2 Selecting Elements
Taught: Element, class, and ID selectors.
Learner Lab: Styles specific paragraphs and headings using classes.
Why It Matters: Allows you to style specific parts of a page differently.
Expected Deliverable: A page with targeted styling.
3 Colors and Typography
Taught: Hex codes, RGB, font-family, and text alignment.
Learner Lab: Applies a cohesive color scheme and custom fonts.
Why It Matters: Defines the visual theme of the website.
Expected Deliverable: A visually appealing web page.
4 The Box Model Basics
Taught: Margin, padding, and borders.
Learner Lab: Creates styled buttons and spaced-out sections.
Why It Matters: Controls spacing and layout of elements.
Expected Deliverable: A neatly laid out and formatted web page.
🛠️ Hands-on Lab: Apply a full CSS stylesheet to the two-page website built in Module 3.
📝 Practical Assignment: Submit the complete, styled multi-page website project.
💼 Commercial Application: Web design and UI styling.
🎯 Expected Outcome: Ability to independently style HTML structures using CSS.
