### 2.2 Explicit Non-Goals & Program Boundaries

To preserve academic depth and avoid superficial tool-hopping, the following topics are explicitly out of scope:
* **Training Foundation Models from Scratch:** We do not cover pre-training transformer weights or multi-million-dollar GPU cluster management. We focus on applied systems engineering, inference APIs, retrieval, and fine-tuning evaluation.
* **Low-Level CUDA Kernel Optimization:** We do not write raw C++/CUDA code. We use production Python runtimes, Docker containers, and optimized API endpoints.
* **Passive Theoretical Proofs:** Academic derivations of backpropagation or gradient descent are minimized in favor of empirical debugging, latency optimization, and cost modeling.
* **Outdated Legacy Assistants APIs:** We do not teach the deprecated OpenAI Assistants API (Threads/Runs state machines). We teach modern stateless function calling, the Responses API, and the native OpenAI Agents SDK.

* **Focus:** ReAct cognitive loops, LangGraph state machines, cyclic graphs, memory persistence, multi-agent collaboration, and the OpenAI Agents SDK.

#### Learning Objectives

* Build production-grade single and multi-agent state machines using **LangGraph**.

* Orchestrate multi-agent architectures (Supervisor, Specialist Worker Teams, Hierarchical Handoffs).

#### Detailed Main Topics & Subtopics
* **The Agent Paradigm:** Differences between static pipelines, prompt chains, and autonomous agent loops; the ReAct framework; managing execution limits and runaway recursion.
* **LangGraph Foundations:** Core primitives: State, Nodes, Edges, Conditional Edges, and the compilation into a runnable graph; managing complex typing with `TypedDict`.

## 13. Security, Governance & OWASP 2026 Compliance

All student deliverables must pass rigorous security standards reflecting the **OWASP Top 10 for Large Language Model Applications (2025/2026 Edition)**:

1. **Defensive Prompt Boundaries (LLM01 - Prompt Injection):** Students must use XML boundary tags (`<user_input>`, `<system_rules>`) and system prompt isolation to prevent adversarial override from untrusted web or document text.
2. **Automated PII Sanitization (LLM02 - Sensitive Information Disclosure):** Student pipelines must incorporate automated regex and named-entity recognition (NER) scrubbers that redact personal identifiable information (credit cards, phone numbers, government IDs) before transmitting data to external model APIs.
3. **Least-Privilege Tool Execution (LLM06 - Excessive Agency):** Agent tools that interact with databases must execute via read-only database roles (`SELECT` only). High-risk operations (modifying records, sending outbound communications) must require explicit human-in-the-loop approval.
4. **Zero Secrets in Git History:** Students must configure `.gitignore` for `.env` files and use environment variables for all API keys. Any student commit containing an exposed secret results in immediate code rejection.
