### Detailed Module Breakdowns

#### MONTH 1: ARCHITECTURAL FUNDAMENTALS, DRAFTING & CAD-TO-3D WORKFLOW (40 HOURS)

##### Module 01: Architectural Fundamentals & Visualisation Standards
- **Guided Instructional Hours:** 14 Hours (Week 1 to Week 2)
- **Primary Software:** AutoCAD 2026/2027, PureRef, Adobe Bridge
- **Learning Objectives:**
  - Read and decode professional architectural blueprints, floor plans, sections, and elevation drawings.
  - Understand real-world architectural scale, structural dimensions, standard wall thicknesses, door/window heights, and sill levels.
  - Master architectural composition theory: rule of thirds, leading lines, one-point vs two-point perspective, eye-level framing, and vertical tilt correction.
  - Establish a clean professional digital studio directory structure, naming conventions, and asset management protocol.
- **Main Topics & Detailed Subtopics:**
  1. *Architectural Drawing Literacy:* Plan types (floor plans, site plans, reflected ceiling plans, elevations, sections); architectural symbols, dimensional strings, finish schedules.
  2. *Spatial Standards & Anthropometry:* Standard interior dimensions (countertops, door lintels, stairs, risers, treads, ceiling heights); imperial and metric standards.
  3. *Visual Composition in ArchViz:* Camera placement psychology, focal points, camera elevation heights (human eye-level at 1.5m, drone/bird's-eye view, worm's-eye view); eliminating vertical perspective distortion.
  4. *Project Organization:* Studio asset bin structure, reference board creation using PureRef, and client project folders.
- **Classroom Labs:** Deconstructing 3 complete architectural plan sets (residential villa, apartment flat, commercial storefront); assembling reference moodboards in PureRef.
- **Student Practical Assignments:** Audit an architect-supplied blueprint set, highlight all structural elements, and produce a photographic reference deck illustrating desired materials and lighting moods.
- **Assessment Criteria:** Plan decoding accuracy (100%), scale comprehension (100%), composition layout analysis rubric.
- **Portfolio Contribution:** Curated architectural reference deck and project pre-visualization moodboard.

##### Module 02: AutoCAD Drafting & CAD-to-3D Workflow
- **Guided Instructional Hours:** 26 Hours (Week 2 to Week 4)
- **Primary Software:** Autodesk AutoCAD 2026/2027, 3ds Max 2026/2027
- **Learning Objectives:**
  - Audit, clean, and standardize messy external CAD drawings for 3D modeling import.
  - Strip redundant text, hatches, dimensions, and blocks, isolating structural walls, openings, and levels.
  - Verify origin point (0,0,0) placement and uniform drawing unit conversions (Millimeters to Centimeters/Meters).
  - Execute error-free CAD cross-section alignment and plan linking into Autodesk 3ds Max.
- **Main Topics & Detailed Subtopics:**
  1. *CAD Interface & Precision Tools:* Units setup, drawing limits, Object Snaps (Osnap), Object Snap Tracking, polar tracking.
  2. *Drawing Sanitization:* Layer isolation (`LAYISO`), Purge (`PURGE`), Audit (`AUDIT`), Overkill (`OVERKILL` to delete overlapping duplicate lines), flattening 3D CAD lines to zero Z-plane (`FLATTEN`).
  3. *CAD-to-3D Preparation:* Creating unified boundary polylines (`BPOLY`, `PEDIT`), separating structural walls, doors, windows, and partition layers.
  4. *Importing into 3ds Max:* File linking vs importing, unit conversion validation, incoming layer management, derived object settings, and spline vertex welding.
- **Classroom Labs:** Sanitizing a multi-story residential floorplan in AutoCAD; importing into 3ds Max and setting up a clean 4-view modeling grid.
- **Student Practical Assignments:** Complete full sanitization of a complex 2500 sq. ft. residential villa plan and export layer-separated, 0,0,0-centered DWG files ready for modeling.
- **Assessment Criteria:** Zero duplicate line geometry, clean layer isolation, 100% unit match in 3ds Max.
- **Portfolio Contribution:** Sanitized CAD drafting package and synchronized 3ds Max modeling template.

##### Module 03: 3ds Max Architectural Modeling
- **Guided Instructional Hours:** 26 Hours (Week 5 to Week 7)
- **Primary Software:** Autodesk 3ds Max 2026/2027
- **Learning Objectives:**
  - Construct watertight architectural walls, floor slabs, ceilings, and structural columns with millimeter accuracy.
  - Master spline modeling: Extrude, Sweep, Bevel Profile for baseboards, crown moldings, and architectural cornices.
  - Execute non-destructive modeling workflows using the 3ds Max modifier stack (Edit Poly, Shell, Symmetry, Chamfer).
  - Model complex custom doors, windows, glazing systems, and curtain walls with real-world reveal details.
- **Main Topics & Detailed Subtopics:**
  1. *Spline & Poly Foundations:* Vertex, Segment, Spline sub-objects; 2.5D and 3D snapping; Editable Poly sub-object mastery (Vertex, Edge, Border, Polygon, Element).
  2. *Architectural Structural Modeling:* Tracing CAD underlays, generating clean interior/exterior walls with door/window cutouts using Connect, Slice, and Bridge (avoiding destructive Booleans).
  3. *Architectural Millwork & Trim:* Creating custom baseboards, ceiling coves, wainscoting, and door architraves using Sweep and Bevel Profile modifiers.
  4. *Fenestration & Glazing Systems:* Double-glazed window assemblies, aluminum mullions, silicone joints, sliding door tracks, and structural glass balustrades.
  5. *Staircases & Level Transitions:* Modeling straight, L-shaped, spiral, and cantilevered floating architectural staircases with handrails.
- **Classroom Labs:** Building a complete multi-room luxury penthouse shell from sanitized CAD plans, complete with floor finishes, ceiling recesses, and window assemblies.
- **Student Practical Assignments:** Model the entire architectural structure of a 2-story contemporary residential villa, ensuring zero mesh intersections and correct real-world dimensions.
- **Assessment Criteria:** Dimensional precision, clean quad-dominant topology, zero non-manifold geometry, non-destructive modifier stack discipline.
- **Portfolio Contribution:** Base architectural 3D shell for Project 01 (Residential Interior) and Project 02 (Commercial Exterior).

  - Utilize parametric scattering and array modeling for repeating architectural elements (railings, louvers, acoustic panels).
- **Main Topics & Detailed Subtopics:**
  1. *Subdivision Surface Modeling:* Quad modeling philosophy, edge weighting, crease values, Turbosmooth with isoline display, control loops for crisp furniture borders.
  2. *Upholstered Furniture Creation:* Modeling modern sofas, ergonomic armchairs, and beds with plush pillows, piping seams, and subtle imperfections.
  3. *Hard-Surface Props & Lighting Fixtures:* Modeling designer pendant lights, dining tables, architectural hardware, faucets, and cabinetry joinery.
  4. *Parametric Array Workflows:* Using 3ds Max Array tool, Clone modifier, and Path Deform for architectural facades, brise-soleil louvers, and decorative partitions.
- **Classroom Labs:** Modeling a high-end designer lounge chair (e.g., Eames Lounge or modern Scandinavian armchair) with soft cushions and wooden shell.
- **Student Practical Assignments:** Model a complete living room furniture set (sofa, coffee table, accent chair, pendant light) matching authentic luxury catalog references.
- **Assessment Criteria:** Organic realism of cushions, edge control under subdivision, accurate proportions relative to human ergonomics.
- **Portfolio Contribution:** Hero furniture asset pack suitable for photorealistic interior visualization.

#### MONTH 3: SCENE ASSEMBLY, UVW MAPPING & PHYSICALLY BASED MATERIALS (40 HOURS)

##### Module 05: Asset Workflow, Topology & Scene Optimization
- **Guided Instructional Hours:** 12 Hours (Week 9 to Week 10)
- **Primary Software:** Autodesk 3ds Max 2026/2027, Trimble SketchUp (Import), Chaos Cosmos
- **Learning Objectives:**
  - Audit external 3D asset libraries (Chaos Cosmos, Quixel, 3dsky, SketchUp 3D Warehouse) and sanitize imported meshes.
  - Optimize scene polygon counts using ProOptimizer and convert high-density geometry into V-Ray Proxies (`.vrmesh`).
  - Implement disciplined scene organization: layers, selection sets, groups vs assemblies, and XRef Scenes.
  - Eliminate memory bottlenecks to enable rendering of scenes containing tens of millions of polygons.
- **Main Topics & Detailed Subtopics:**
  1. *External Asset Ingestion:* Cleaning dirty CAD and SketchUp geometry, resetting transformations (`Reset XForm`), fixing inverted surface normals (`Normal` modifier).
  2. *V-Ray Proxy Architecture:* Converting multi-million polygon trees, vegetation, and ornate decor into `.vrmesh` proxies with viewport display overrides (bounding box, point cloud).
  3. *Scene Management & Organization:* Standardized layer naming (`ARCH_Walls`, `ARCH_Glazing`, `FURN_Loose`, `LIGHT_Interior`, `VEG_Exterior`); managing 3ds Max Scene Explorer.
  4. *Memory & Performance Optimization:* Instance vs Reference duplicates, RAM usage analysis, Bitmap Paging, and scene cleanup utilities.
- **Classroom Labs:** Importing 50 high-poly decorative assets and vegetation into a villa scene; proxying and instancing to reduce RAM consumption from 24GB to 4GB.
- **Student Practical Assignments:** Assemble a fully populated residential living, dining, and kitchen environment with zero system instability or viewport lag.
- **Assessment Criteria:** Viewport FPS responsiveness, proper layer isolation, 100% of vegetation and repetitive furniture instanced/proxied.
- **Portfolio Contribution:** Fully populated and optimized 3D interior master scene.

##### Module 06: UV Mapping, PBR & V-Ray Materials
- **Guided Instructional Hours:** 28 Hours (Week 10 to Week 12)
- **Primary Software:** Autodesk 3ds Max, Chaos V-Ray 7, Adobe Photoshop (Texture maps)
- **Learning Objectives:**
  - Master UVW mapping coordinates: Box, Planar, Cylindrical, and Unwrapping complex organic surfaces.
  - Understand the physics of light-matter interaction: Refraction, Reflection, Fresnel effect, IOR (Index of Refraction), and Microfacet Roughness/Glossiness.
  - Build photorealistic V-Ray Materials (VRayMtl) for architectural surfaces: polished concrete, hardwood parquet, brushed metals, architectural glass, velvet, leather, and translucent marble.
  - Integrate advanced procedural maps: VRayColor2Bump, VRayDirt (ambient occlusion/weathering), VRayDistanceTex, and Triplanar mapping.
- **Main Topics & Detailed Subtopics:**
  1. *UVW Mapping Foundations:* Real-World Map Size workflows, UVW Map modifier, adjusting tiling, orientation, and seam placement.
  2. *PBR Material Physics:* Diffuse/Albedo (avoiding pure 0 black and pure 255 white), Reflection, Glossiness vs Roughness, Fresnel reflections, Metalness workflow.
  3. *Advanced Architectural Shaders:*
     - *Glass & Liquids:* Architectural glass vs thick refractive glass, thin-walled reflections, tinted glass, frosted glass.
     - *Wood & Stone:* Parquet flooring with color variance, polished marble with realistic normal maps and roughness maps.
     - *Metals:* Brushed brass, anodized aluminum, black matte steel, chrome (IOR values and anisotropic highlights).
     - *Fabrics:* Velvet sheen using VRaySheen / falloff maps, woven linen with normal detail, translucent curtains with two-sided materials (VRay2SidedMtl).
  4. *Displacement & Procedural Detailing:* VRayDisplacementMod for stone masonry and rugs; Triplanar mapping to texture complex geometry without UV seams.
- **Classroom Labs:** Creating a material library of 15 photorealistic architectural shaders from scratch; setting up a standardized studio shader ball testing rig.
- **Student Practical Assignments:** Texture the entire Project 01 luxury interior scene, ensuring authentic surface imperfections, realistic wood grain scale, and tactile fabric bump.
- **Assessment Criteria:** Accurate IOR and roughness calibration, zero texture stretching, appropriate bump/normal scale, absence of tiling artifacts.
- **Portfolio Contribution:** Professional 15-shader material library and textured master interior scene.

#### MONTH 4: PHYSICAL CINEMATOGRAPHY, DAYLIGHTING & ADVANCED RENDERING (40 HOURS)

##### Module 07: V-Ray Cameras & Physical Lighting
- **Guided Instructional Hours:** 20 Hours (Week 13 to Week 15)
- **Primary Software:** Autodesk 3ds Max 2026/2027, Chaos V-Ray 7
- **Learning Objectives:**
  - Operate the V-Ray Physical Camera using real-world photography parameters: Focal Length, F-Number (Aperture), Shutter Speed, and ISO sensitivity.
  - Control camera exposure, depth of field (DoF), motion blur, and perspective vertical tilt correction.
  - Construct physical daylight systems using VRaySun, VRaySky, and calibrated high-dynamic-range (HDRI) environmental dome lights.
  - Deploy interior artificial illumination: VRayLight (Plane, Disc, Sphere, Mesh) and IES photometric lights for architectural recessed spotlights.
- **Main Topics & Detailed Subtopics:**
  1. *Physical Camera Mechanics:* Sensor size, focal length selection (24mm wide-angle interior vs 50mm natural perspective vs 85mm architectural detail vignette); Exposure Value (EV) calculation.
  2. *Natural Daylighting:* VRaySun position, turbidity, ozone, solar intensity; HDRI dome lighting setup, rotating sun orientation to cast compelling architectural shadows.
  3. *Artificial & Interior Lighting:* Color temperature (Kelvin scale: 2700K warm residential to 5500K daylight); VRayLight types; loading manufacturer IES profiles for realistic light throw.
  4. *Light Balancing Principles:* Hierarchy of light (Key light, Fill light, Accent light); balancing intense natural window daylight with subtle interior mood lighting.
- **Classroom Labs:** Setting up 3 distinct lighting moods on a single interior scene: Bright Morning Sunlight, Overcast Diffused Day, and Dramatic Blue-Hour Evening with warm interior lights.
- **Student Practical Assignments:** Execute photographic camera framing and dual-scenario lighting (Daylight & Evening) for the Project 01 luxury interior.
- **Assessment Criteria:** Photographic exposure balance without clipped highlights, natural shadow falloff, realistic color temperature contrast.
- **Portfolio Contribution:** Dual-lighting portfolio stills (Daylight & Blue Hour Evening) for Project 01.

  2. *Vegetation Scattering:* Surface distribution of architectural landscaping, scale and rotation variance, camera clipping to conserve memory.
  3. *Exterior Daylighting Scenarios:* High noon commercial lighting, low-angle golden hour residential lighting, and dramatic night architectural illumination with facade uplighting.
  4. *V-Ray Frame Buffer Mastery:* Layer-based corrections in VFB 2: Exposure, White Balance, Filmic Tonemap, LUT application, Hue/Saturation, and real-time bloom & glare.
- **Classroom Labs:** Setting up exterior commercial building lighting and scattering 50,000 grass blades and 200 trees around the site perimeter using Chaos Scatter.
- **Student Practical Assignments:** Light and render a hero exterior camera angle of Project 02 (Commercial Architectural Exterior) during Golden Hour with lush landscaping.

## 6. Mandatory Model Context Protocol (MCP) Security & Sandboxing Plan

### 6.1 Architectural Overview
The Model Context Protocol (MCP) is an open protocol enabling AI systems to interact with external tools and execution environments. When applied to 3D computer graphics software like Blender, the system operates across four discrete layers:

```
┌─────────────────────────────────────────────────────────────┐
│                      1. AI CLIENT                           │
│   (Claude Desktop / Antigravity Agent / Developer IDE)      │
└──────────────────────────────┬──────────────────────────────┘
                               │  JSON-RPC Protocol
┌──────────────────────────────▼──────────────────────────────┐
│                  2. BLENDER MCP SERVER                      │
│     (Local Node.js / Python Process exposing tool schema)   │
└──────────────────────────────┬──────────────────────────────┘
                               │  Local IPC / TCP Socket
┌──────────────────────────────▼──────────────────────────────┐
│                  3. BLENDER ADD-ON / LISTENER               │
│     (Python Add-on running inside Blender execution space)  │
└──────────────────────────────┬──────────────────────────────┘
                               │  Internal Execution
┌──────────────────────────────▼──────────────────────────────┐
│                  4. BLENDER PYTHON API (bpy)                │
│    (Inspects scene, creates meshes, manipulates materials)  │
└─────────────────────────────────────────────────────────────┘
```

### 6.2 Threat Model & Vulnerability Analysis
The official Blender Foundation MCP server documentation explicitly warns that AI-generated Python scripts execute directly inside Blender's embedded Python runtime. Because Python possesses full operating system privileges, an unconstrained MCP connection introduces severe security risks:
1. **Arbitrary Code Execution:** An LLM may generate code using Python's `os`, `subprocess`, `shutil`, or `socket` modules, potentially altering system files outside the 3D application.
2. **Data Deletion / File Overwriting:** Unintended script bugs or hallucinations can overwrite project assets, delete system directories, or corrupt scene databases.
3. **Network Exfiltration:** A malicious prompt injection could cause an unmonitored script to read local files and transmit them to external servers.
4. **Host System Crash / Infinite Loops:** Poorly bounded geometric loops (e.g. subdividing a mesh 15 times) can instantly exhaust host RAM and crash the operating system.

### 6.3 Mandatory Classroom Sandbox Safeguards
To expose students safely to cutting-edge AI-assisted 3D workflows without risking production data or hardware stability, Nova Skills enforces strict sandbox controls:

```
┌────────────────────────────────────────────────────────────────────────┐
│                   MANDATORY MCP SANDBOX ARCHITECTURE                   │
│                                                                        │
│   [ISOLATED VIRTUAL MACHINE / LAB CONTAINER]                           │
│   ├── Dedicated ephemeral VM (Windows Sandbox / Hyper-V / Docker)      │
│   ├── Outbound Network Firewall: BLOCKED (Except local loopback)       │
│   ├── Host Drive Sharing: DISABLED (Zero shared folders)               │
│   ├── Storage: Disposable practice .blend files only                   │
│   ├── Credentials: ZERO stored tokens, passwords, or personal keys     │
│   ├── Execution Policy: Human-in-the-Loop Explicit Approval for Writes │
│   └── Instant Rollback: Snapshot restoration after every session       │
└────────────────────────────────────────────────────────────────────────┘
```

#### Strict Execution Rules:
1. **Never on Host Machines:** Live MCP server connections to Blender are **strictly forbidden** on personal laptops or production workstations containing personal data or client projects.
2. **Disposable Scene Files:** Students only test scripts on disposable, non-sensitive primitive benchmark files.
3. **Explicit Write Confirmation:** The MCP server must be configured to prompt for explicit human confirmation before executing any write, modify, or file-saving action.
4. **No Autonomous Loops:** Students are prohibited from granting "unsupervised autonomous execution" rights to any AI agent connecting to DCC software.
5. **Fallback Pedagogical Mode:** If an adequately isolated VM sandbox cannot be provisioned on a student workstation, the instructor will deliver **static architectural demonstrations, pre-recorded code walkthroughs, and reviewed offline Python scripts** rather than connecting a live, unguarded MCP socket.
