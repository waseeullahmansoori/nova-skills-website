## 7. Excluded Routes & Exclusion Justification

The following URLs and routes are deliberately excluded from `sitemap.xml`:

| Path / Pattern | Reason for Exclusion | Enforcement Mechanism |
|---|---|---|
| `404.html` | Error handling template; indexing error states wastes crawl budget | Excluded in `generate-sitemap.js`, `<meta name="robots" content="noindex, nofollow" />` |
| `admin.html`, `admin-activity.html`, `admin-settings.html`, `admin/` | Internal administrative tools; private | Excluded in generator, `robots.txt` Disallow, auth-protected |
| `login.html`, `student.html`, `portal.html`, `register.html` | Student login / authentication gateways | Excluded in generator, `robots.txt` Disallow, meta `noindex` |
| `ai-chat.html` | Standalone AI assistant interface | Excluded in generator, `robots.txt` Disallow |
| `thank-you/`, `lead-success/` | Post-conversion confirmation pages; indexing pollutes lead analytics | Excluded in generator, `robots.txt` Disallow, `_headers` `X-Robots-Tag: noindex, follow` |
| `academy-detail.html`, `blog-detail.html` | Legacy client-side redirect templates | Excluded in generator, meta `noindex, follow`, redirected via JS/Cloudflare |
| `/course-detail.html` (bare without ID) | Generic template with no course context | Excluded in generator, 301 redirected to `/courses` at edge |
| `.html` variants of clean root pages | Non-canonical aliases (e.g. `/courses.html`) | Excluded in generator, 301 redirected to clean URLs |
